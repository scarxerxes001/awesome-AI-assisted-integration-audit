# Tools and Libraries

## 1. FActScore

A factuality evaluation package based on atomic facts and evidence support.

- Repository: https://github.com/shmsw25/FActScore
- Paper: https://aclanthology.org/2023.emnlp-main.741/
- Useful for: long-form factual precision evaluation.

## 2. SelfCheckGPT

A black-box hallucination detection implementation based on consistency across sampled generations.

- Paper: https://aclanthology.org/2023.emnlp-main.557/
- Implementation: https://github.com/potsawee/selfcheckgpt
- Useful for: detecting potentially non-factual statements without requiring model probabilities.

## 3. OpenFactCheck

A unified framework for customized fact-checking and LLM factuality evaluation.

- Repository: https://github.com/yuxiaw/OpenFactCheck
- Paper: https://aclanthology.org/2025.coling-main.755/
- Useful for: claim verification, document checking, and LLM factuality evaluation.

## 4. Hugging Face Evaluate

A general evaluation library supporting metrics, comparisons, measurements, and model/dataset evaluation workflows.

- Documentation: https://huggingface.co/docs/evaluate/
- Repository: https://github.com/huggingface/evaluate
- Useful for: reproducible evaluation pipelines and standard metrics.

## 5. Long-form Factuality / SAFE

Google DeepMind's implementation accompanying work on long-form factuality. It includes LongFact prompts and the Search-Augmented Factuality Evaluator (SAFE).

- Repository: https://github.com/google-deepmind/long-form-factuality
- Paper: https://arxiv.org/abs/2403.18802
- Useful for: long-form factuality benchmarking and automated evidence-based evaluation.
