# Primary-source verification notes (13 November 2026)

The following URLs were checked against primary scholarly pages or the model/dataset publisher when preparing this package. These checks verify publication identity and resource existence; they do not establish novelty of the current study.

- **PubMedQA:** Jin et al., 2019, *PubMedQA: A Dataset for Biomedical Research Question Answering*, ACL Anthology `https://aclanthology.org/D19-1259/`, DOI `10.18653/v1/D19-1259`. The original defines yes/no/maybe biomedical QA with contexts and an expert-labeled subset of 1,000.
- **FActScore:** Min et al., 2023, EMNLP; bibliographic information and DOI in the uploaded review; publisher page `https://aclanthology.org/2023.emnlp-main.741/` (publication reference only; method not executed).
- **ALCE:** Gao et al., 2023, *Enabling Large Language Models to Generate Text with Citations*, ACL Anthology `https://aclanthology.org/2023.emnlp-main.398/`, DOI `10.18653/v1/2023.emnlp-main.398`. Cited generation and citation quality are distinct from simple PubMedQA classification.
- **FELM:** Chen et al., NeurIPS 2023, publisher `https://proceedings.neurips.cc/paper_files/paper/2023/hash/8b8a7960d343e023a6a0afe37eee6022-Abstract-Datasets_and_Benchmarks.html`. Fine-grained segment factuality annotations and evaluation of factuality evaluators.
- **Model:** Qwen2.5-0.5B-Instruct model card `https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct` documents 0.49B parameters and Apache-2.0.
- **Dataset and code:** `https://github.com/pubmedqa/pubmedqa`, official README and MIT license file `https://github.com/pubmedqa/pubmedqa/blob/master/LICENSE`.

No claim of a globally new technique, official PubMedQA leaderboard replication, or paid API access is made. Record source/access dates in new runs because web and model repositories can change.
