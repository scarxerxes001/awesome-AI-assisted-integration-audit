# GitHub Implementations

These repositories provide publicly available code/data associated with factuality, hallucination, scientific verification, or evaluation research.

## 1. FActScore

https://github.com/shmsw25/FActScore

Implementation of the FActScore method for evaluating factual precision in long-form generations.

## 2. SciFact

https://github.com/allenai/scifact

Official data and models for scientific claim verification, including pretrained components and evaluation resources.

## 3. Long-form Factuality

https://github.com/google-deepmind/long-form-factuality

Official implementation containing LongFact, SAFE, evaluation scripts, and benchmarking pipelines.

## 4. TRUE

https://github.com/google-research/true

Code and data accompanying the TRUE factual-consistency evaluation study.

## 5. CONNER

https://github.com/ChanLiang/CONNER

Implementation and resources for the CONNER framework from the EMNLP 2023 paper on comprehensive evaluation of LLM-generated knowledge.

### Additional repository

**TruthfulQA:** https://github.com/sylinrl/TruthfulQA

The official benchmark repository contains the benchmark data and evaluation code for TruthfulQA.
