# Tutorials and Learning Resources

## 1. TruthfulQA Paper and Benchmark

https://aclanthology.org/2022.acl-long.229/

A good starting point for understanding truthfulness evaluation and benchmark construction.

## 2. SciFact Paper and Scientific Claim Verification

https://aclanthology.org/2020.emnlp-main.609/

Introduces scientific claim verification and provides the conceptual basis for evidence-based scientific factuality evaluation.

## 3. FActScore Paper

https://aclanthology.org/2023.emnlp-main.741/

Useful for learning how long-form LLM outputs can be decomposed into atomic facts and evaluated against evidence.

## 4. Hugging Face Evaluate Documentation

https://huggingface.co/docs/evaluate/

Covers installation, evaluation modules, metrics, evaluators, and practical model/dataset evaluation workflows.

## 5. Hugging Face Evaluate Quick Tour

https://huggingface.co/docs/evaluate/main/a_quick_tour

A practical introduction to loading evaluation modules and using metrics, comparisons, and measurements.

## 6. SelfCheckGPT Paper

https://aclanthology.org/2023.emnlp-main.557/

Explains a sampling-based approach to detecting hallucinations in black-box LLM outputs.

## 7. RAGTruth Paper

https://aclanthology.org/2024.acl-long.585/

Useful for understanding hallucination evaluation in retrieval-augmented generation systems.

## 8. Factuality of Large Language Models: A Survey

https://aclanthology.org/2024.emnlp-main.1088/

A broad overview of factuality definitions, evaluation methods, challenges, and research directions.

## Suggested learning path

1. Start with **TruthfulQA** to understand truthfulness benchmarks.
2. Study **SciFact** to move into scientific evidence verification.
3. Learn **FActScore** for long-form factuality.
4. Study **SelfCheckGPT** and **RAGTruth** for hallucination detection.
5. Use **Hugging Face Evaluate** to build reproducible evaluation experiments.
