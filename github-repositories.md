# GitHub Implementations

- **[FActScore](https://github.com/shmsw25/FActScore)** - Official code for atomic-fact factuality evaluation; directly implements the FActScore paper.
- **[FELM](https://github.com/google-research/google-research/tree/master/felm)** - Research code and benchmark resources for factuality evaluation of LLMs.
- **[SelfCheckGPT](https://github.com/potsawee/selfcheckgpt)** - Reference implementation for sampling-based hallucination detection.
- **[HaluEval](https://github.com/RUCAIBox/HaluEval)** - Dataset and evaluation resources for hallucination benchmarking.
- **[SciFact](https://github.com/allenai/scifact)** - Data processing and baseline code for scientific claim verification.
- **[MedQA](https://github.com/jind11/MedQA)** - Benchmark data and baselines for medical question answering.
- **[ChemCrow](https://github.com/ur-whitelab/chemcrow-public)** - Public implementation of the chemistry tool-augmented agent described by Bran et al.

Before reuse, check each repository's licence, maintenance status, dependencies, and evaluation protocol.
