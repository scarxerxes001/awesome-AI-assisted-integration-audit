# Tools and Libraries

- **[Hugging Face Evaluate](https://huggingface.co/docs/evaluate/)** - Reusable evaluation modules and comparisons for ML experiments.
- **[EleutherAI Language Model Evaluation Harness](https://github.com/EleutherAI/lm-evaluation-harness)** - Widely used framework for reproducible LLM benchmark evaluation.
- **[Ragas](https://docs.ragas.io/)** - Framework for evaluating retrieval-augmented generation, including faithfulness and context relevance.
- **[LlamaIndex](https://docs.llamaindex.ai/)** - Data and retrieval framework for building evidence-connected LLM applications.
- **[LangChain](https://python.langchain.com/docs/introduction/)** - Framework for tool and retrieval orchestration; use with explicit source tracking.
- **vLLM](https://docs.vllm.ai/)** - High-throughput inference engine suitable for repeatable local or server evaluation runs.

Tool output is not a substitute for a documented evaluation protocol, fixed model version, prompt record, and human review where the application demands it.
